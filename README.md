# WAR ARENA – Battle of Legends

A simple browser-based turn-based game developed using Object-Oriented Programming (OOP) concepts.

## 🎮 Overview

Two players select characters (Warrior, Mage, Archer) and battle each other.
Each character has health, attack power, and a special ability.
Players take turns to attack, heal, or use special ability until one player wins.

## 🧠 OOP Concepts Used

* Classes and Objects
* Inheritance
* Polymorphism
* Encapsulation
* Abstraction

## 🛠️ Technologies

* HTML
* CSS
* JavaScript (ES6 Classes)

## ▶️ How to Run

{ https://wararenabol.vercel.app }

## 📌 Features

* Turn-based gameplay
* Character selection
* Attack, Heal, Special Ability
* Health tracking and winner detection
